# Task completion reports

Every refinement task produces a report here: `<TASK-ID>-report.md`.

See [ISKONNECT_PRODUCT_REFINEMENT_MASTER_PLAN.md](../ISKONNECT_PRODUCT_REFINEMENT_MASTER_PLAN.md) §6.7 for the template and workflow.

Reports are committed on the same branch as the code change and merged with the task.
